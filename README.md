# Apostolu's Theme

My dark theme for Python and C. Installing this package also installs the following for semantic token parsing,

- [clangd](https://marketplace.visualstudio.com/items?itemName=llvm-vs-code-extensions.vscode-clangd)
- [Python](https://marketplace.visualstudio.com/items?itemName=anysphere.cursorpyright) (Anysphere)
- [Python](https://marketplace.visualstudio.com/items?itemName=ms-python.python) (ms-python)
